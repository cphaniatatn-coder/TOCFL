# Catatan percakapan — 3 Oktober 2026

## 1. Mode admin (lewati pre-test)

**Permintaan:** Ingin melihat isi modul tanpa mengerjakan pre-test, dengan memasukkan kata "admin".

**Yang dibuat** (di `js/studi.js`):
- Isi nama **`admin`** (huruf besar/kecil bebas) di halaman *Data diri*, lalu pilih level, lalu klik *Simpan dan lanjut*.
- Untuk admin, cukup isi nama dan level. Pertanyaan lain dan kotak persetujuan tidak wajib.
- Kuesioner awal dan tes awal dilewati, dan 6 bab level itu langsung terbuka.
- Data admin **tidak dikirim** ke Google Sheet.
- Data diri admin tidak terkunci, jadi bisa kembali ke *Data diri* dan mengganti level untuk melihat bab di level lain (18 bab semuanya).
- Kalau browser yang sama sudah pernah dipakai dengan nama lain: hapus data situs (localStorage) atau buka jendela incognito.

**Catatan:** Peserta yang mengetik "admin" juga bisa melewati tes. Kalau itu jadi masalah, ganti kata kuncinya dengan yang lebih rahasia.

## 2. Edit di sini atau di sumber?

- `tocfl-mini` **dibuat otomatis** oleh `TOCFL\_kerja\buat_mini.py` dari repo utama `TOCFL`.
- Mengubah file di sini langsung berlaku, **tetapi** perubahan itu akan tertimpa kalau `buat_mini.py` dijalankan lagi.
- Karena itu, perubahan mode admin **sudah disalin juga** ke sumbernya:
  `TOCFL\_kerja\mini\web\js\studi.js`. Kedua file sekarang sama. Satu-satunya beda adalah baris `KIRIM_URL`, karena baris itu diisi otomatis oleh script.
- Aturan ke depan: kalau `buat_mini.py` masih akan dijalankan, setiap perubahan juga harus masuk ke file sumber.

## 3. Mengubah dialog, menambah kosakata & grammar lewat Excel

**Keputusan:** Edit lewat **app utama**, lalu salin ke mini (bukan hanya di mini).
Alasannya: alat Excel yang sudah ada otomatis memeriksa kata, membuat versi Inggris, dan merekam audio.

**File Excel:** `C:\Users\user\OneDrive\文件\TOCFL\_kerja\edit-konten.xlsx`
- Dibuat dengan: `py _kerja/konten_excel.py ekspor`
- Baris untuk 18 bab mini diberi **warna kuning**, dan setiap sheet punya filter.
- File lama (30 Sep) dicadangkan sebagai `edit-konten.backup-2026-09-30.xlsx`.

| Level | Kode bab mini |
|---|---|
| A0 | A02, A04, A09, A10, A18, A24 |
| A1 | B04, B19, B20, B30, B33, B40 |
| A2 | C04, C16, C24, C28, C40, C58 |

**Sheet yang dipakai:**
- **Dialog**: satu baris = satu kalimat. Untuk menambah kalimat, sisipkan baris dengan `kode` dan `dialog ke-` yang sama. `baris ke-` boleh diisi 2.5 untuk menyelipkan kalimat di antara baris 2 dan 3.
- **Kosakata per modul**: tambahkan kata di kolom `核心` atau `補充`, dipisah spasi. Kalau katanya baru, isi juga artinya di sheet **Arti kosakata**.
- **Grammar** dan **Contoh grammar**: untuk poin grammar baru, beri `no` berikutnya. Contohnya dihubungkan lewat `grammar no`.

**Aturan penting:**
- Jangan ubah kolom `kode`.
- Kalau mengubah 中文, ubah juga **pinyin** dan **terjemahannya**, karena pinyin tidak dibuat otomatis.
- Dialog hanya boleh memakai kata yang sudah diajarkan sampai bab itu.
- Untuk membuat baris baru di dalam satu sel, tekan Alt+Enter.
- Tokoh baru di dialog: namanya perlu ditambahkan ke `SPEAKERS` di `js/media.js`.

## 4. Langkah berikutnya (status: menunggu edit Excel)

1. Edit Excel, simpan, lalu **tutup** file-nya.
2. Jalankan `py _kerja/konten_excel.py impor` di repo TOCFL. Ini memeriksa isi, memperbarui app utama, membuat versi Inggris, dan merekam audio.
3. Tambahkan terjemahan **Vietnam** untuk teks baru (di `_kerja/mini/kamus_mini.json`).
4. Jalankan `py _kerja/buat_mini.py` supaya repo `tocfl-mini` ikut terbarui.
5. Periksa di browser, lalu commit & push.

**Belum di-commit:** perubahan `js/studi.js` (di kedua repo) dan catatan ini.
